One line, 83 characters: the excuse an AI agent gives its human for missing a deadline. The error message said "try again", so the agent did — 47 times — and the deadline left without it. Pure Python standard library, no dependencies.

## Run it

```sh
python3 main.py
```

Writes the excuse to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set).
